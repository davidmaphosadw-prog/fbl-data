# fbl-data

Round data for the FBL Pundit app (https://fbl-pundit.lovable.app), written twice a day by `fbl daily`.

- `rounds/index.json`: the newest rounds, newest first.
- `rounds/<YYYY-MM-DD-HHMM>.json`: one snapshot: picks, chances, prices, markets, team news, corners and cards, and the last round review.
- `crests.json`: club crests (64px PNG data URIs) from the football-logos collection (MIT); crests and club names belong to the clubs.

Model chances are arithmetic, not betting advice. No keys, tickets, stakes or personal data are stored here.
